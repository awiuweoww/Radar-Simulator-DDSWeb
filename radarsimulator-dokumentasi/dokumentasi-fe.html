Integrasi Peta Taktis OpenLayers

Peta pada dashboard ini bukan sekadar tampilan statis, melainkan sebuah Tactical Map Engine yang dirancang untuk menangani ratusan objek bergerak secara real-time dengan performa tinggi.

Transformasi Koordinat & Proyeksi

Data dari OpenDDS biasanya datang dalam format Geografis (WGS84: Longitude, Latitude). Karena OpenLayers menggunakan proyeksi Web Mercator (EPSG:3857), setiap paket data ditransformasi menggunakan fungsi fromLonLat() sebelum ditampilkan:

const coords = fromLonLat([t.lon, t.lat]);
feature.getGeometry().setCoordinates(coords);

Sinkronisasi Visual (Radar Sweep)

Elemen "Sapuan Radar" (Sweep) disinkronkan secara dinamis dengan resolusi peta. Ini memastikan ukuran sapuan tetap akurat terhadap skala geografis (misal: radius 45km) meskipun pengguna melakukan Zoom In/Out.

const diameterPx = (radiusMeter * 2) / map.getView().getResolution();
sweepElement.style.width = `${diameterPx}px`;



Bagaimana mengatur Pub, Sub, & Topic di WebDDS

Implementasi WebDDS pada Frontend mengikuti standar OMG (Object Management Group) yang mengabstraksi komunikasi biner DDS menjadi operasi berbasis Web (JSON/WebSocket).

1. Konsep Dasar

  • Topic: Sebuah "saluran" data yang diidentifikasi oleh nama unik dan tipe data tertentu (berdasarkan IDL).
  • Subscriber: Entitas yang mendaftarkan diri (subscribe) ke sebuah Topik untuk menerima data secara otomatis setiap kali ada update.
  • Publisher: Entitas yang memiliki kemampuan untuk menulis (write) data ke sebuah Topik.

2. Syntax Umum (WebDDS Standard)

// Membuat Topik (Nama, TipeData)
const myTopic = new Topic("UserPos", "MyIDL::Position");

// Berlangganan Data (Subscriber)
participant.subscribe(myTopic, (data) => {
    console.log("Data Diterima:", data);
});

// Menyiapkan Pengiriman (Publisher)
const writer = participant.publish(myTopic);
writer.write({ x: 10, y: 20 });

Syarat & Prasyarat Penting

Agar mekanisme Pub/Sub dapat berjalan tanpa error, ada beberapa syarat teknis yang wajib dipenuhi:

  • Domain ID Matching: Frontend harus menggunakan Domain ID yang sama dengan Backend (default: 0). Pengaturan ini dilakukan saat memanggil dds.createParticipant(0).
  • Case-Sensitive Topic: Nama Topik (misal: RadarTrackTopic) dan Nama Tipe Data (misal: RadarTrack::TrackData) harus **sama persis** karakternya dengan yang didefinisikan di file IDL Backend.
  • Konektivitas Gateway: Pastikan variabel lingkungan (.env) sudah mengarah ke URL Gateway yang aktif (REST & WebSocket). 
    VITE_DDS_GATEWAY_REST=http://localhost:8080/dds
VITE_DDS_GATEWAY_WS=ws://localhost:8080/dds
  • QoS Compatibility: Pastikan kebijakan QoS (Reliability, Durability, dll) yang diminta oleh Frontend tidak "lebih berat" daripada yang ditawarkan oleh Backend (Rx <= Tx).


Bagaimana mengatur QoS di WebDDS pada FE

Dalam arsitektur project ini, kebijakan Quality of Service (QoS) dikelola secara terpusat pada DDS Gateway. Hal ini dilakukan untuk menjamin konsistensi dan memudahkan pemeliharaan tanpa perlu melakukan konfigurasi manual di sisi browser.

Sentralisasi QoS di Gateway

Meskipun Frontend mengirim data melalui WebSocket, Gateway-lah yang menentukan bagaimana data tersebut dikirimkan ke jaringan DDS biner. Contohnya:

  • Transparansi: Developer FE cukup fokus pada data JSON. Gateway secara otomatis menerapkan RELIABLE dan TRANSIENT_LOCAL untuk setiap perintah yang dikirim.
  • Konsistensi: Dengan mengatur QoS di Gateway, kita memastikan seluruh client Web (jika ada lebih dari satu) memiliki profil koneksi yang identik dan kompatibel dengan Backend C++.

*Untuk melihat detail implementasi kode QoS, silakan merujuk ke Bab 6: Dokumentasi Gateway.

Bagaimana mengatur & mengkompile IDL di FE

Agar struktur data di Frontend selalu sinkron dengan Backend tanpa menulis ulang kode, kami menggunakan Universal IDL-to-TS Compiler kustom.

⚠️ Konteks & Keterbatasan OpenDDS

Berbeda dengan beberapa kompetitor DDS komersial (seperti RTI Connext yang memiliki Web Integration Service resmi), OpenDDS saat ini belum memiliki tool generator resmi untuk ekosistem Web/JavaScript.

  • Tanpa Tool Bawaan: OpenDDS tidak menyertakan binary seperti opendds_js_gen untuk mengonversi IDL ke TypeScript secara otomatis.
  • Solusi Kustom: Oleh karena itu, di project ini kami membangun script idl-compiler.js secara mandiri sebagai jembatan (bridge) agar tipe data biner tetap bisa dibaca dengan aman di browser.
  • Perbandingan: Pada platform lain, proses ini biasanya sudah include dalam tools SDK mereka, namun di OpenDDS kita harus melakukan parsing manual terhadap file IDL.

1. Lokasi & Pemetaan Folder

Proses kompilasi mengikuti aturan pemetaan folder sebagai berikut:

  • Source (Input): src/idl/<Folder>/<NamaFile>.idl
  • Destination (Output): src/types/<NamaFile>.ts

Contoh: src/idl/RadarTrack/RadarTrack.idl akan diubah menjadi src/types/RadarTrack.ts.

2. Perintah Eksekusi

Jalankan perintah berikut di terminal (root folder fe-webdds):

node scripts/idl-compiler.js src/idl/RadarTrack/RadarTrack.idl src/types/RadarTrack.ts

Full Source Code: scripts/idl-compiler.js

Berikut adalah kode lengkap dari script compiler yang digunakan untuk mentransformasi skema IDL menjadi TypeScript:

/**
 * UNIVERSAL OMG IDL to TypeScript Compiler
 * -----------------------------------------
 * Dirancang khusus untuk ekosistem OpenDDS/DDS-WEB.
 * Mendukung: Struct, Enum, Module, Sequence, Typedef, dan Anotasi (@).
 */

const fs = require('fs');
const path = require('path');

const TYPE_MAP = {
    'long': { ts: 'number', read: 'reader.readInt32()' },
    'unsigned long': { ts: 'number', read: 'reader.readUint32()' },
    'long long': { ts: 'number', read: 'Number(reader.readInt64())' },
    'short': { ts: 'number', read: 'reader.readInt16()' },
    'double': { ts: 'number', read: 'reader.readFloat64()' },
    'float': { ts: 'number', read: 'reader.readFloat32()' },
    'octet': { ts: 'number', read: 'reader.readUint8()' },
    'char': { ts: 'string', read: 'String.fromCharCode(reader.readUint8())' },
    'string': { ts: 'string', read: 'reader.readString()' },
    'boolean': { ts: 'boolean', read: 'reader.readBoolean()' }
};

class IDLCompiler {
    constructor() {
        this.typedefs = {};
        this.enums = {};
    }

    cleanSource(source) {
        source = source.replace(/\/\/.*$/gm, '');
        source = source.replace(/\/\*[\s\S]*?\*\//g, '');
        source = source.replace(/@\w+(\s*\([\s\S]*?\))?/g, '');
        return source.trim();
    }

    parse(source) {
        source = this.cleanSource(source);
        const results = { modules: [], structs: [], enums: [], typedefs: [] };

        const tdRegex = /typedef\s+sequence<([\w\s<>]+)>\s+(\w+);/g;
        let tdMatch;
        while ((tdMatch = tdRegex.exec(source)) !== null) {
            this.typedefs[tdMatch[2]] = { type: tdMatch[1].trim(), isSequence: true };
        }

        const enumRegex = /enum\s+(\w+)\s*\{([\s\S]*?)\};/g;
        let eMatch;
        while ((eMatch = enumRegex.exec(source)) !== null) {
            const name = eMatch[1];
            const values = eMatch[2].split(',').map(v => v.trim()).filter(v => v);
            this.enums[name] = values;
            results.enums.push({ name, values });
        }

        const structRegex = /struct\s+(\w+)\s*\{([\s\S]*?)\};/g;
        let sMatch;
        while ((sMatch = structRegex.exec(source)) !== null) {
            const name = sMatch[1];
            const body = sMatch[2];
            const fields = [];
            const fieldRegex = /([\w\s<>]+)\s+(\w+);/g;
            let fMatch;
            while ((fMatch = fieldRegex.exec(body)) !== null) {
                let type = fMatch[1].trim().replace(/\s+/g, ' ');
                const fieldName = fMatch[2].trim();

                if (type.startsWith('sequence<')) {
                    const inner = type.match(/sequence<([\w\s<>]+)>/)[1].trim();
                    fields.push({ name: fieldName, type: inner, isSequence: true });
                } else if (this.typedefs[type]) {
                    fields.push({ name: fieldName, type: this.typedefs[type].type, isSequence: this.typedefs[type].isSequence });
                } else {
                    fields.push({ name: fieldName, type, isSequence: false });
                }
            }
            results.structs.push({ name, fields });
        }
        return results;
    }

    generate(idlName, data) {
        let code = `/**\\n * Auto-generated by Universal IDL Compiler\\n * Source: ${idlName}.idl\\n */\\n\\n`;
        code += `import { CDRReader } from '../utils/CDRReader';\\n\\n`;

        data.enums.forEach(e => {
            code += `export enum ${e.name} {\\n`;
            e.values.forEach((v, i) => code += `  ${v} = ${i},\\n`);
            code += `}\\n\\n`;
        });

        data.structs.forEach(s => {
            code += `export interface ${s.name} {\\n`;
            s.fields.forEach(f => {
                let tsType = TYPE_MAP[f.type]?.ts || f.type;
                if (f.isSequence) tsType += '[]';
                code += `  ${f.name}: ${tsType};\\n`;
            });
            code += `}\\n\\n`;
        });

        data.structs.forEach(s => {
            code += `export class ${s.name}Codec {\\n`;
            code += `  static decode(reader: CDRReader): ${s.name} {\\n`;
            code += `    return {\\n`;
            s.fields.forEach(f => {
                if (f.isSequence) {
                    const isPrimitive = !!TYPE_MAP[f.type];
                    const readerCall = isPrimitive ? `() => reader.${TYPE_MAP[f.type].read}` : `() => ${f.type}Codec.decode(reader)`;
                    code += `      ${f.name}: reader.readSequence(${readerCall}),\\n`;
                } else if (this.enums[f.type]) {
                    code += `      ${f.name}: reader.readInt32() as ${f.type},\\n`;
                } else if (TYPE_MAP[f.type]) {
                    code += `      ${f.name}: ${TYPE_MAP[f.type].read},\\n`;
                } else {
                    code += `      ${s.name}: ${f.type}Codec.decode(reader),\\n`;
                }
            });
            code += `    };\\n`;
            code += `  }\\n`;
            code += `}\\n\\n`;
        });
        return code;
    }
}

const args = process.argv.slice(2);
const compiler = new IDLCompiler();
const rawSource = fs.readFileSync(args[0], 'utf8');
const parsedData = compiler.parse(rawSource);
const generatedCode = compiler.generate(path.basename(args[0], '.idl'), parsedData);
fs.writeFileSync(args[1], generatedCode);
console.log(`✅ IDL Compiled: ${path.basename(args[0])}`);
